# XZDH 个人网站

这是一个基于原生 HTML/CSS/JavaScript 的个人主页项目，主要用于展示个人信息、项目经历、博客文章和关于页面。

## 项目简介

该网站包含以下几个页面：

- 首页：个人展示页，包含头像、简介和社交入口
- 项目页：展示已完成/正在进行的项目卡片
- 博客页：发布学习笔记、比赛题解和项目更新
- 关于页：介绍站点和作者说明

它的风格偏向清新、可爱、现代化的个人博客风，适合用作个人作品集或技术博客。

## 项目结构

```text
website/
├── index.html          # 首页
├── project.html        # 项目页
├── blog.html           # 博客页
├── about.html          # 关于页
├── images/             # 图片资源
├── music/              # 音乐相关资源
├── articles/           # 文章页面
├── README.md           # 项目说明
└── ...
```

## 运行方式

这是一个静态网站，不依赖任何后端框架或构建工具。你可以直接在浏览器中打开以下文件：

```bash
index.html
```

或者使用本地 Web 服务器进行预览，例如：

```bash
cd website
python -m http.server 8000
```

随后访问：

```text
http://localhost:8000/
```

## 特点

- 纯静态页面，部署简单
- 适配移动端浏览器
- 页面间跳转清晰，导航统一
- 支持背景图片、悬浮动画和卡片式布局
- 个人社交入口直接链接到 GitHub、Bilibili 等平台

## 维护建议

- 新增页面时可以保持同样的导航结构
- 图片资源统一放在 `images/` 目录中
- 文章内容建议放入 `articles/` 下，并保持命名规范
- 如需更新个人资料、项目链接或文章内容，可以直接编辑对应 HTML 文件
